# Wygenerowane modele bębnów ściegowych (A1, B1, C1, D)

Katalog zawiera gotowe modele parametryczne OpenSCAD (`.scad`) oraz wyrenderowane bryły siatek trójwymiarowych (`.stl`), gotowe do bezpośredniego pocięcia w slicerze i druku 3D.
